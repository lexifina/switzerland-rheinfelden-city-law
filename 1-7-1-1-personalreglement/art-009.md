# § 9 Beendigung
1 Das Anstellungsverhältnis kann jederzeit im gegenseitigen Einvernehmen beendet werden.
2 Das Anstellungsverhältnis endet ausserdem durch:
a) ordentliche Kündigung: Die Kündigung des Anstellungsverhältnisses kann – vorbehalten längerer Fristen im Vertrag – beidseitig unter Einhaltung nachstehender Fristen erfolgen:
1. während der Probezeit 7 Tage auf das Ende einer Kalenderwoche;
2. im ersten Anstellungsjahr 1 Monat auf Monatsende;
3. im überjährigen Anstellungsverhältnis 3 Monate auf Monatsende;
4. Die Kündigung durch die Gemeinde erfolgt mit schriftlicher Begründung.
b) Aus wichtigen Gründen kann das Anstellungsverhältnis jederzeit fristlos gekündigt werden; die Artikel 337 ff. OR sind anwendbar.
c) Pensionierung.
